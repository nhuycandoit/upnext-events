# upnext-events
Event list for nextstepgen.com

## What's here
- `events.json` — the opportunity feed that nextstepgen.com syncs daily (via `EVENTS_FEED_URL`).
- Raw URL for the site: https://raw.githubusercontent.com/nhuycandoit/upnext-events/main/events.json
- Each listing has an `external_id`, a `last_checked` date, and notes on what was verified on the official source.
- `"status": "archived"` tells the site to archive that listing. Nothing is ever deleted by the feed.
